## Step 1: A kinfo_proc that does not fit reads as "can't tell"
**Goal**: Classify `sysctl`'s `ENOMEM` as `Unusable`, so an unexpectedly larger `kinfo_proc` gives `None`, as the docs promise.
**Implementation Logic**:
1. `src/gpu/kinfo.rs`: add `/// ENOMEM from <errno.h>: …` `pub(super) const ENOMEM: i32 = 12;` beside `ESRCH`. In `classify_kern_proc_pid`, before the `rc != 0` → `Refused` return: `if rc != 0 && errno == ENOMEM { return PidLookup::Unusable; }`. XNU copies a record only when it fits (`sysdoproc_callback`), and `sysctl_prochandle` returns `ENOMEM` with `len` 0 when `needed > oldlen`, so this is the signature of a larger record. Do not narrow `Refused` to `EPERM`.
2. Tests in `kinfo::tests`: add `classify_kern_proc_pid_a_record_that_does_not_fit_is_unusable` (`classify_kern_proc_pid(-1, 12, &[0; 648], 0, 0) == PidLookup::Unusable`, literal `12`), and in `decide_exists_follows_the_lookup_rule` the row `Failed { errno: 3 }` with a closure returning `classify_kern_proc_pid(-1, 12, &[0; 648], 0, 0)` gives `None`.
3. Docs, each written as the final state: `PidLookup::Unusable`'s doc ("the call succeeded but…": it also covers a record that does not fit, `ENOMEM`); the `classify_kern_proc_pid` doc (the `rc` paragraph: `ENOMEM` is `Unusable`, any other failure `Refused`); `kern_proc_pid_raw`'s rustdoc in `src/gpu/metal.rs` (`ENOMEM` classifies as `Unusable`, "can't tell"); the macOS "`None` when" cell of `process_exists`'s table in `src/gpu/mod.rs` (add: or the `kinfo_proc` record does not fit, `ENOMEM`); `docs/roadmap-v0.2.14.md` lines ~150-151: replace "so the whole-records length check stays the parser's only guard against a layout that differs" with a sentence naming both guards, the whole-records length check and the PID cross-check, and saying that a record which does not fit makes `sysctl` fail with `ENOMEM`, which reads as "can't tell". If the CHANGELOG's `process_exists` bullet lists the `None` cases, add this one there too.
**Deliverables**: `src/gpu/kinfo.rs` (`ENOMEM`, the `classify_kern_proc_pid` arm, two docs, two tests); `src/gpu/metal.rs` (`kern_proc_pid_raw` rustdoc); `src/gpu/mod.rs` (`process_exists` macOS cell); `docs/roadmap-v0.2.14.md` (the guard sentence)
