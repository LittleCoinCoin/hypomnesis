## Step 2: Implement the dispatcher, the decision and the variant
**Goal**: Make `gpu_process_listing` the one dispatcher, `gpu_processes` its wrapper, and `ProcessListDenied` the answer to an enumerated but unreadable list.
**Implementation Logic**:
1. `src/gpu/mod.rs::process_list_denied(others_read, denied)`: `Some(denied)` only when `others_read == 0 && denied > 0`, with the count as `u32::try_from(denied).unwrap_or(u32::MAX)`; otherwise `None`.
